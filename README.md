# Otomieru Boyer

Linux向けの耳コピ支援アプリケーションです。音源をスペクトログラムとピアノロールで確認しながら、区間ループ、比較ループ、音程を維持した速度変更、EQ、音高メモを使って音を聴き取れます。

![Otomieru Boyer screenshot](assets/screenshot-main.png)

## 主な機能

- WAV / MP3 / FLAC / OGG / M4A / AAC の読み込みと再生
- スペクトログラムとピアノロールによる音高表示
- 再生・一時停止・停止・シーク、タイムラインでの区間ループと範囲消去
- `Original → Notes → Mix`を1周ずつ繰り返す比較ループ
- 音程を保つ速度変更（0.50x〜1.50x）と独立したオクターブシフト
- 5バンドEQ（100 Hz / 250 Hz / 1 kHz / 4 kHz / 10 kHz、各±12 dB）
- 表示専用の基音強調（キー／スケールまたは12音の個別指定）
- スペクトログラム上の確認音、音色選択、A4=430〜450 Hzのチューニング
- 原曲音量と確認音量の独立調整
- 6固定レイヤーの音高メモ作成・移動・削除・リサイズ・Undo、可変長メモ設置
- 音高メモを原曲と同時に再生して確認する答え合わせ再生
- 音源ごとのsidecar JSONへの保存・自動読込
- 同一音源の再読込を高速化するスペクトログラム解析キャッシュ
- マウス操作プリセット・個別設定、メニューバー、操作ガイド

## 基本操作

| 操作 | 内容 |
| --- | --- |
| スペクトログラム上でホイール | 時間軸を拡大／縮小 |
| スペクトログラム上でCtrl＋ホイール | 音高方向を拡大／縮小 |
| スペクトログラム上でShift＋ホイール | 時間表示を移動 |
| スペクトログラム下部の横バー | 時間方向の表示範囲を移動（再生中も可） |
| スペクトログラム右端の縦バー | 音高方向の表示範囲を移動。バー外へ出てもドラッグ中は継続 |
| 停止中に左クリック | 再生位置を移動し、押下中は対応音を確認 |
| 停止中に左ダブルクリック | 選択中レイヤーへ長さ0.5秒の音高メモを作成 |
| 停止中にShift＋左ドラッグ（既定） | 押下位置から解放位置までの可変長音高メモを作成 |
| メモ上で右クリック | メモを削除 |
| メモの左右端を右ドラッグ | メモの開始位置または長さを変更 |
| メモ中央を右ドラッグ | メモを時間・音高方向へ移動 |
| `Ctrl+Z` | メモの作成・削除・移動・変更を取り消す（テキスト入力中は入力欄のUndoを優先） |
| `Ctrl+S` または ファイル → 保存 | プロジェクトを保存 |

有効なループ範囲を再生中は、音高メモの追加・削除・移動・リサイズ・Undoを行えます。Loop OFFまたは範囲なしの通常再生中は編集できません。`比較`はLoop ONかつ有効な範囲があるときだけ有効で、Originalでは原曲のみ、Notesでは現在のレイヤーMute・音量設定に従うメモのみ、Mixでは両方を再生します。Loop横の`消去`は範囲と比較を解除し、その後の`|<`で曲先頭へ戻れます。

メモが重なる場合、選択中レイヤーを優先して操作対象を決めます。

## 分析ツールと設定

メニューバーの`分析ツール`から、リサイズ・スクロール可能なダイアログを開きます。`EQ`、`基音強調`、`音色`、`チューニング`、`レイヤー`は、今聴いている音を調べるための道具群です。それぞれ折り畳め、説明は各見出しのⓘで確認できます。

マウス操作は`設定 → マウス操作…`で変更します。操作プリセット、ホイール3操作、可変長メモ設置の修飾キーを設定でき、曲別sidecarとは別のユーザー共通設定として保存されます。操作方法は`ヘルプ → 操作ガイド`で確認できます。

- `試聴音量`はスペクトログラムを押している間の確認音だけに作用します。
- `原曲音量`は読み込んだ音源の再生音だけに作用します。
- レイヤーごとの表示、Mute、音量、透明度は実行中だけの設定です。起動・再読込時には全レイヤーが「表示ON、Mute OFF、音量100%、透明度100%」へ戻ります。
- レイヤー名と音高メモ、曲固有のEQ・基音強調・チューニングは保存されます。

## 保存ファイル

保存先は音源と同じフォルダの`<音源ファイル名>.otomieru.json`です。例: `song.flac` → `song.flac.otomieru.json`。

解析結果は別途`<音源ファイル名>.otomieru.spectrum.bin`へ保存され、同じ音源を再度開く際のSTFT・スペクトログラム解析を省略します。再生用の音声デコードは毎回行います。キャッシュが壊れているか音源・解析条件と一致しない場合は、自動的に再解析します。

保存データには音源照合情報、曲固有設定、6レイヤーのID・名前・音高メモを含めます。レイヤーの表示、Mute、音量、透明度、選択状態、再生速度、オクターブ、原曲音量、確認音量、音色は保存しません。旧ファイルにレイヤーの実行時設定が含まれていても読み込めますが、その値は使用せず初期値へ戻します。

## 描画性能

スペクトログラムは表示幅に合わせて解析フレームを集約し、テクスチャへキャッシュします。再生中はキャッシュ、再生線、ガイド、音高メモだけを描画します。表示範囲、表示サイズ、音程範囲、表示ゲイン、基音強調、EQ、音源が変わったときだけキャッシュを再生成します。

## 動作要件

- Linux の音声出力環境
- Rust（edition 2024対応の安定版）
- Rubber Band Library 3.x の開発パッケージ
- 日本語UI表示用の Noto Sans CJK または IPAex フォント

Ubuntu / Debian系では、次を導入します。

```bash
sudo apt-get install librubberband-dev pkg-config fonts-noto-cjk
```

# OtoMieru Boyer v0.3.0 ― 音高メモ仕様

## 1. 目的

音高メモは、耳コピ中にユーザーが判断した音高を音源の時間軸上へ視覚的に記録し、試聴音として原曲と同時再生して確認する機能。

自動採譜・MIDI編集・楽譜作成を目的としない。

基本的な作業ループは次のとおり。

> 見る → 聴く → 音高を推測 → メモを置く → 原曲と同時再生 → 耳で確認 → 修正

## 2. 音高メモの基本概念

音高メモは「音符」ではなく、音源上に置く伸縮可能な付箋とする。

最低限、次の情報を持つ。

```rust
struct PitchMemo {
    start_sec: f64,
    duration_sec: f64,
    pitch: i32,
}
```

| 項目 | 意味 |
| --- | --- |
| `start_sec` | 音源上の開始位置 |
| `duration_sec` | 試聴音を鳴らす長さ、および画面上のメモ範囲 |
| `pitch` | 音高 |

`duration_sec` は音楽的な音価を意味しない。四分音符・八分音符などの概念は持たない。

## 3. 編集操作

スペクトログラム／ピアノロールと同じ時間×音高座標上で直接編集する。既存の左ボタンによる試聴操作を維持するため、音高メモの作成・編集はダブルクリックと右ボタン操作へ分離する。

| 操作 | 結果 |
| --- | --- |
| 左単押し・左長押し | 従来どおり、位置移動および押下中の試聴 |
| 左ダブルクリック | クリック位置の時間・音高に、長さ0.5秒の音高メモを作成 |
| 音高メモ上で右クリックして離す | 対象の音高メモを削除 |
| 音高メモの左端／右端で右ボタンを押してドラッグ | 左端／右端をリサイズ |
| `Ctrl+Z` | 直前の作成・削除・移動・音高変更・長さ変更を取り消す |

右ボタン操作は、押下後に一定距離以上動かした場合をリサイズ、動かさずに離した場合を削除として判定する。これにより、右端をつかんでゆっくり操作しても、削除せずに長さを変更できる。

リサイズ用のハンドルは音高メモの左右端に表示し、ハンドル上ではリサイズ用カーソルを表示する。音高メモが重なった場合、右クリックは最前面のメモ（選択中レイヤーを優先）の1件に適用する。

基本操作はこれだけとする。BPM、拍、小節、クオンタイズ、グリッドスナップ、ベロシティ等は扱わない。

## 4. 答え合わせ再生

音高メモが存在する区間を再生すると、現在の試聴音設定を使ってメモを発音する。

既存の次の設定をそのまま利用する。

- 音色：ピアノ／シンセストリングス／矩形波
- 試聴チューニング：例として A4 = 444.5 Hz

これにより、原曲と音高メモを同時に聴き、人間が正誤を判断する。アプリ自身は「正解」「不正解」の判定を行わない。

## 5. レイヤー

複数の音高メモレイヤーを持てる構造にする。

例：`Bass`、`Harmony`、`Melody`

用途はパート別の耳コピ整理。各レイヤーは最低限、次の操作を持つ。

- 表示／非表示
- Mute／Unmute
- 音量
- 透明度

表示と発音は独立させる。

| 表示 | 発音 | 用途 |
| --- | --- | --- |
| ON | ON | 通常の答え合わせ |
| OFF | ON | 目を使わず耳だけで確認 |
| ON | Mute | スペクトログラムとメモだけを比較 |

レイヤー管理は低頻度操作のため、通常UIでは簡略表示し、詳細設定側へ置いてよい。

### レイヤーの着色

各音高メモレイヤーには、レイヤー識別用の色を自動で割り当てる。これは装飾ではなく、同一時間・同一音高で複数レイヤーのメモが重なった場合でも、所属レイヤーを視覚的に判別できるようにするためのものとする。

- レイヤー作成時に固定パレットから色を自動割り当てする。
- ユーザーによる自由な色指定、および色編集UIは設けない。
- 主要な識別色は6色程度を用意し、1〜6レイヤー目には異なる色を使う。
- 7レイヤー目以降を許可する場合は共通色（白など）を使ってよい。
- 音高メモの矩形は、レイヤー色とレイヤーごとの`opacity`を組み合わせて描画する。

色はレイヤーの表示順ではなく、作成時に与える永続的なレイヤーIDの順で決定する。これにより、レイヤーの削除や将来の並べ替えによって既存レイヤーの色が変わらない。

```text
Layer ID 1 → Palette 1
Layer ID 2 → Palette 2
...
Layer ID 6 → Palette 6
Layer ID 7+ → Default color
```

`color_index`などの色を保存する項目はv0.3.0では持たない。将来、パレットの割当規則を変更しても既存レイヤーの色を厳密に維持する必要が生じた場合にのみ追加する。

v0.3.0では、カラーピッカー、RGB／HEXによる自由色指定、レイヤーごとの色編集UI、無制限に識別可能な色の用意は行わない。

> **色はレイヤーを見分けるためだけに使う。色を編集する機能にはしない。**

## 6. 保存

音高メモはユーザーが作成した再生成不能データのため、プロジェクトとして永続化する。

```text
音源
 │
 ├─ プロジェクトデータ
 │    ├─ 音高メモ
 │    ├─ レイヤー
 │    └─ 曲固有設定
 │
 └─ 再生成可能データ
      └─ スペクトログラム等
```

初期段階では、音源と同じフォルダに置くsidecar JSONで十分とする。保存ファイル名は、音源の拡張子を残した`<音源ファイル名>.otomieru.json`とする。

例：`song.flac` → `song.flac.otomieru.json`

### 保存対象

保存する項目は、音源を解釈して耳コピ作業を進めるための設定と、再生成不能な作業成果に限定する。

| 設定 | 保存 | 理由 |
| --- | --- | --- |
| A4基準Hz | する | 音源そのものに対するチューニング解釈 |
| EQ | する | その音源を聞き取るために作った調整 |
| 基音強調 | する | その曲・パートを解析するための調整 |
| 音高メモ | する | 作業成果 |
| レイヤー | する | 作業成果の構造 |
| 再生速度 | しない | その瞬間の聴き方 |
| オクターブ変更 | しない | その瞬間の聴き方 |
| 試聴音量・音色 | しない | その瞬間の聴き方 |

基音強調には、強調率、キー、スケール、個別に選択した音、指定外音程の減衰率を含める。EQには5バンドの各ゲインを含める。

```json
{
  "format_version": 1,
  "audio": {
    "file_name": "song.flac",
    "file_size_bytes": 12345678,
    "modified_unix_ms": 1735689600000,
    "duration_seconds": 245.31,
    "sample_rate_hz": 44100
  },
  "project_settings": {
    "preview_reference_a4_hz": 444.5,
    "equalizer_gains_db": [0.0, -2.0, 1.5, 0.0, 0.0],
    "fundamental_analysis": {
      "emphasis": 60.0,
      "scale_root": 0,
      "scale_preset": "major",
      "emphasized_pitch_classes": [true, false, true, false, true, true, false, true, false, true, false, true],
      "unemphasized_pitch_attenuation": 30.0
    }
  },
  "layers": [
    {
      "id": 1,
      "name": "Bass",
      "visible": true,
      "muted": false,
      "volume": 0.7,
      "opacity": 0.6,
      "memos": [
        {
          "id": 1,
          "start_sec": 12.43,
          "duration_sec": 0.8,
          "pitch_midi": 40
        }
      ]
    }
  ]
}
```

`format_version` は OtoMieru Boyer のアプリ版ではなく、保存形式のバージョンとする。将来スキーマを変更した際のmigration判定に使用する。

`audio`には、sidecarの対象となる音源を確認するための情報を記録する。音源の絶対パスは保存せず、sidecarと同じフォルダにある`file_name`を対象とする。ファイル名、サイズ、更新日時、長さ、サンプルレートが一致しない場合は、別音源へメモを適用する可能性を警告する。

## 7. v0.3.0では扱わないこと

- 自動音高推定
- 正誤判定
- BPM推定
- 拍・小節の管理
- 音価の管理
- クオンタイズ
- ベロシティの管理
- MIDI CC
- VST
- エフェクトによる音作り
- 楽譜作成
- MIDI export（少なくともv0.3.0の対象外）

これらを対象外とすることで、シーケンサーへ機能が膨張することを防ぐ。

## 8. v0.3.0の機能を一文で

> **音高メモ：耳コピした音高を原曲の時間軸上に付箋のように書き込み、その音を原曲と一緒に鳴らして耳で確認する。**

より短く表すなら、次のとおり。

> **見つけた音を、書いて、重ねて、聴き直す。**

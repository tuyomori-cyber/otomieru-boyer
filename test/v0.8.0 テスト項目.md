# v0.8.0 テスト項目

## 目的

v0.8.0の`The World -Spectral Freeze-`を確認する。再生位置の周波数成分を保持して継続出力し、原曲の時間・Loop折返し・比較パターンのフェーズ遷移を停止すること、ならびに通常再生へ安全に復帰することを確認する。`0.00x（The World）`は保存される速度値ではなく、The Worldの開始・解除入口として扱う。

- `[OK]`: 確認済み・問題なし
- `[ ]`: 未確認
- `[NG]`: 確認済み・問題あり
- 実機確認時は、OS、デスクトップ環境、音声デバイス、音源形式・チャンネル数、再生速度、Loop範囲のおおよその長さ、比較フェーズを各項目末尾へ記録する。
- 音切れ・クリック・残音は、ヘッドホンまたは十分に小さいバッファサイズで確認する。

# 前提認識

- v0.4.0では「有効なループ再生中のみ、音高メモの設置・編集・Undoを許可」する。
- ループ範囲は編集操作の解禁条件として扱い、新規配置・移動・リサイズの既存編集規則そのものは維持する。
- 既存のループ範囲外メモは削除・変更せず、表示・保存したまま残す。
- ループ外へはみ出すメモの再生挙動は、ループ境界で発音が切れることを許容する。
- 音高メモの右ドラッグ中は時間・音高ズームを禁止する。
- 現在の表示範囲をまたぐループは作れないため、再生ヘッド追従による表示範囲送りを原因とするドラッグ中の時刻対応問題はv0.4の対象外とする。
- 比較UIはLoopとは独立したON/OFFを持つが、Loop OFF時は比較もOFFとする。
- Loop ONのままStopした場合は比較ONを維持し、再開時に比較を続けられる状態を保つ。
- 比較中もレイヤーごとのMute・音量を変更せず、そのまま発音条件として利用する。
- 比較中もレイヤーミキサーは操作可能とする。
- 比較の各フェーズでは、Originalでは原曲のみ、Notesでは音高メモ、Mixでは原曲と音高メモを発音対象とする。Notes/Mixでは各レイヤーのMute・音量をそのまま適用する。
- `Original`では音高メモを一時的に全Muteする。これはレイヤー設定値自体を変更せず、比較フェーズ中だけ適用する。
- `Notes`／`Mix`では音高メモ側の各レイヤー設定をそのまま使用する。
- 比較ループは内部では固定3状態の直接遷移ではなく、比較ステップのシーケンスとして扱う。
- v0.4の比較シーケンスは`Original → Notes → Mix`の3ステップ固定とし、各ステップを1ループずつ再生する。回数・順序・使用フェーズの設定UIは設けない。
- 比較の進行位置はフェーズ値ではなくシーケンス上の位置として管理し、ループ境界で次の比較ステップへ進められる構造とする。
- 将来、同じフェーズを複数回再生する場合にも対応できるよう、内部では`Original → Original → Notes → Notes → Mix → Mix`のようなシーケンスへ拡張可能な形を維持する。
- 実機テスト項目はv0.4.0と既存機能をまとめた専用ファイルで管理し、未確認項目を順次消化する。
- 実機テスト項目ファイルはルート直下の`test/`で管理し、v0.4.0仕様書から参照する。
- 比較フェーズ中の音高メモ編集について、Original中の編集結果が次のNotesフェーズで発音に反映されること、Notes中の編集で現在発音中の音や次フェーズに異常な残音・二重発音が生じないこと、Mix中の編集が原曲再生へ影響せず次回のNotes/Mixへ反映されることを実機確認対象とする。
- 比較ループ本体、レイヤーミキサー、Transport、音声品質の大半は実機テストで通過しており、現時点の主要な未解決事項は一部のテスト項目と周辺の音声/UI課題に絞られている。

# MVP ゴール

- 有効なループを前提に、ループ再生中の音高メモ編集を安全に行える。
- ループ再生と音高メモ編集、Undo、比較再生が一貫した操作感で成立する。
- 既存メモを壊さず、ループ境界による再生上の挙動を予測可能にする。
- 比較再生時もレイヤーごとのMute・音量を活用して、必要なレイヤーだけを聴き比べられる。
- 比較中もレイヤーミキサーを操作でき、`Original`では音高メモを一時全Mute、`Notes`／`Mix`では現在のレイヤー設定を反映できる。
- 比較ループはv0.4では`Original → Notes → Mix`を各1周、自動的に順番再生できる。
- 比較ループの内部構造は将来の複数回再生やシーケンス変更へ拡張可能な形とする。
- 比較順、比較中のレイヤー設定反映、Stop後の再開について実機確認済みである。
- 比較ループ、レイヤーミキサー、Transport、音声品質の主要機能について実機テストを通過した状態とする。
- テスト結果を`[OK]`／`[NG]`／`[ ]`で明確に判別できる状態とする。
- ループ再生中も表示範囲を手動で移動でき、再生を止めずに確認・編集対象を切り替えられる。
- 音高ズーム後も、縦方向の表示範囲を手動で移動して見切れた音域を確認できる。

# 非ゴール

- 画面をまたぐループ範囲を前提とした再生中ドラッグの表示範囲固定。
- ループ範囲外に既に存在する音高メモの自動削除・自動修正。
- 短いループに合わせた新規音高メモ長の特別な丸め。
- 比較中にレイヤーのMute・音量設定を一時的に上書きして全レイヤーを強制発音する仕様。
- v0.4での比較回数・比較順序・使用フェーズの設定UI。
- v0.4での`Original ×2 → Notes ×2 → Mix ×2`など複数回比較の提供。

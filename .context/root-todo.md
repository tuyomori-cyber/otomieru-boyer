## 持越しの既知課題

- Notes時のノイズの発生源を、比較フェーズ切替時とメモ発音開始時に分けて切り分ける。
- 極小ループ時の再生位置線逸脱は、音声ループとは切り分けられた低優先度課題として扱う。
- 再生ヘッドが表示右端を越える際の自動追従の違和感は、低優先度課題として扱う。

# v0.8以降のロードマップ

## 方針

- v0.8では、再生速度0倍と同義のSpectral Freezeを実装する。
- v0.9では、試聴音エンジンを拡張してMIDIキーボードと追加音色に対応する。

## v0.5.0 — 操作感の改善（完了）
- [x] `Shift + 左ドラッグ`で、押下位置から解放位置までの可変長音高メモを作成できるようにする。左ダブルクリックによる0.5秒メモ設置は維持する。
- [x] 横・縦の表示バーを、クリック位置と表示範囲の中心が一致する操作感へ改善する。
- [x] スペクトログラム上で`Shift + ホイール`による時間方向の表示移動を追加する。既存のホイール／`Ctrl + ホイール`によるズームは維持する。
- [x] 完全カスタマイズは行わず、「既定」「時間移動重視」など少数の操作プリセットを用意する。
- [x] 入力判定と機能実行をアクション単位へ分離し、将来のキー・マウス・MIDI割当に備える。
- [x] 操作プリセットと主要操作を説明するアプリ内ヘルプを追加する。

## v0.6.0 — 解析キャッシュ（リリース済み）

- [x] STFT・スペクトログラムの解析結果を、音源横の専用バイナリキャッシュへ保存する。
- [x] キャッシュをsidecar JSONへ含めず、通常のプロジェクト保存から分離する。
- [x] 音源の照合情報と解析形式バージョンでキャッシュを検証し、不一致・破損時は再解析する。
- [x] キャッシュは一時ファイルを経由して原子的に保存する。
- [x] キャッシュ利用時も再生用の音声デコードは必要であることを仕様として明示する。

## v0.7.0 — ループシーケンサと常用ツールパレット（リリース済み）

- [x] 比較ループを、`Original`・`Notes`・`Mix`を任意順・任意回数で並べられるループシーケンサへ拡張する。UI上では`比較パターン`と表示する。
- [x] 比較ステップの追加、削除、変更を提供する。上限は10件とする。
- [x] ツールバーの`ツール`ボタンから開く、リサイズ・スクロール可能な常用ツールパレットを導入する。
- [x] `EQ`、`基音強調`、`音色`、`チューニング`、`レイヤー`、`比較パターン`を、パレットに登録できるツールとして扱う。
- [x] `ツール → マスターパレット…`で、表示するツールを選択し、既定構成へ復帰できるようにする。
- [x] マスターパレットで、機能名のドラッグにより全ツールの並び順を変更できるようにする。ツールダイアログはこの順番のチェック済み項目だけを表示する。
- [x] パレット構成をユーザー共通の`settings.json`へ保存し、旧設定読込時は既定構成を適用する。曲別sidecarには保存しない。
- [x] 音声コールバックから安全に読める、上限付きのループシーケンサ表現を導入する。
- [x] ループシーケンサの変更時は、ループ始端へ戻して新しい列の先頭から再開する。
- [x] ループシーケンサをユーザー共通の`settings.json`へ保存し、旧設定読込時は既定シーケンスを適用する。曲別sidecarには保存しない。
- [x] v0.7.0の自動・実機確認項目を、既存版と同じ書式で作成した。

## v0.8.0 — Spectral Freeze

- [ ] `T`でトグルする`The World -Spectral Freeze-`、再生メニューの機能項目とタイムストレッチ`0.00x`、速度選択の`0.00x（The World）`を追加する。
- [ ] Freeze用のSTFTフレームを制御側または再生ワーカーで生成し、音声コールバックでは事前生成済みデータだけを合成する。
- [ ] The Worldの開始・解除を20msのequal-powerクロスフェードで接続し、実機テストでクリック・操作感を確認する。
- [ ] 比較フェーズで合成された出力をFreeze対象とし、開始前の再生速度をT解除時に復帰する。音質優先のFFT設定を採用する。
- [ ] Freeze位置のマーカーと停止した再生位置線を表示し、Tでの解除と停止時の必須解除を実装する。
- [ ] Loop・比較の全再生状態から開始可能にし、The World中は再生時間を変更・進行させる操作だけを排他にする。
- [ ] Freeze中は反映不能な音高メモの作成・編集・削除・Undoを無効にし、その他の再生中に可能な操作は既存仕様に従わせる。
- [ ] 先頭・末尾・短尺・無音・モノラル／ステレオでの安全性、NaN／無限値の抑止、クリック・残音を単体・Linux実機で確認する。

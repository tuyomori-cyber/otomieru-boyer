# テーマ

v0.3.0 音高メモ機能の設計確定と実装。

# 参照仕様

- 詳細仕様：`docs/OtoMieru Boyer v0.3.0 ― 音高メモ仕様.md`
- 音高メモは、耳コピした音高を時間×音高座標へ記録し、原曲と重ねて試聴するための機能。
- 自動採譜、正誤判定、拍・小節・クオンタイズ、MIDI編集／出力はv0.3.0の対象外。

# 現在の状態

- Done: v0.2系のスペクトログラム表示・再生線追従・試聴チューニング（A4=430〜450 Hz）を実装済み。
- Done: 音高メモの操作、レイヤー、保存、着色に関するv0.3.0仕様を作成済み。
- Pending: v0.3.0の実装は未着手。

# v0.3.0 実装順

1. プロジェクトデータモデルを追加する。
  - レイヤー、音高メモ、曲固有設定、永続ID、編集状態を定義する。
2. sidecar JSONの読込・保存を追加する。
  - `<音源ファイル名>.otomieru.json`を使用し、音源照合・形式バージョン・値検証・書込エラーを扱う。
3. 音高メモの描画と編集を追加する。
  - 左ダブルクリックによる0.5秒メモ作成、右クリック削除、右ドラッグの左右端リサイズ、`Ctrl+Z`を実装する。
  - メモ描画はスペクトログラムのテクスチャキャッシュと分離する。
4. メモの答え合わせ再生を追加する。
  - 原曲の再生位置、シーク、ループに同期し、既存の音色・試聴チューニングを利用して複数メモを発音する。
5. レイヤー管理UIを追加する。
  - 表示、Mute、音量、透明度、作成・選択・名前変更を扱う。
  - 固定パレットの自動色割当を実装する。
6. 保存・読込・編集・再生・Undoをテストし、実機で操作性を確認する。

# 継続確認

- 旧実機と新実機で、同じ音源・表示倍率・ウィンドウサイズのUI FPSを比較する。
- 実音源で高倍率ズーム時・ループ境界・試聴チューニングの聴感上の一致を確認する。
- 高リフレッシュレート環境で、60 FPSを超える再生線更新が必要か確認する。

# 非ゴール

- v0.3.0の音高メモ実装を理由に、スペクトログラム本体の毎フレーム再構築へ戻さない。
- 保存形式を、仕様にない汎用MIDI編集形式へ拡張しない。

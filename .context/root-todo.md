# 前提・制約

- レイヤー数は6固定。追加、削除、並べ替え、色編集は行わない。
- 保存するのは曲固有設定、レイヤーID・名前、音高メモのみ。実行時UI状態は保存しない。
- 自動採譜、正誤判定、BPM・拍・小節、クオンタイズ、MIDI編集／出力はv0.3.0の対象外。
- 音高メモ実装を理由に、スペクトログラム本体の毎フレーム再構築へ戻さない。
- v0.4.0項目1では、停止中は従来どおり編集可能とし、再生中は有効なループ再生中のみ音高メモの設置・削除・移動・リサイズ・Undoを許可する。
- ループ無効の通常再生中は音高メモ編集を禁止する。
- スペクトログラム上の試聴音は、既存どおり再生状態を問わず利用可能とする。
- v0.4.0項目1では、再生中のシーク、ページバー移動、速度・EQ変更は対象外とし、既存の停止中限定を維持する。
- ループ再生中の編集可否は、単にUIの`Loop`チェック状態だけではなく、正規化済みで音声フレーム上も有効なループ範囲が存在することを条件とする。
- 再生側のループ境界は整数フレームへ丸めず`f64`で保持しており、`end > start`なら有効とする。最小ループ長は必須の安全条件とはせず、必要なら操作感のための任意制約として扱う。
- 再生中の移動・リサイズは、まずボタンを離した時点で編集を確定し、次回の同期で発音へ反映する方針を基本とする。
- 現在の実装では画面をまたぐループ範囲を指定できず、ループ範囲は現在の表示範囲内に収まる。このため、ループ再生中の再生ヘッド追従によって画面が次へ送られ、ドラッグ中のポインタと時刻の対応が変化するケースはv0.4の短区間ループ用途では想定しない。
- 再生ヘッド追従による画面送りを前提としたドラッグ中の表示範囲固定は、完全異常系として対象外とする。
- 音高メモの右ドラッグ中は、時間・音高ズームを禁止する。
- 再生中の音高メモの新規配置・移動・リサイズは、ループ範囲内に収めることを必須とせず、既存の編集規則を維持する方向を基本とする。
- 既存のループ範囲外メモは表示・保存したまま残し、再生中の新規配置・移動・リサイズでもループ境界によるデータのクランプ・改変は行わない方向で整理する。
- ループ範囲外へはみ出すと、完全にループ外のメモはその周回で再生されず、ループ開始前・終了後へはみ出すメモは境界で途中開始・途中切断され得るため、再生結果の予測が難しくなる。
- ループ範囲内への配置制約は編集許可条件の代替にはせず、範囲未設定や無効なループでは編集を禁止する。
- 再生中の試聴音と編集操作が競合するため、ダブルクリックによる追加時の試聴音の扱いを確認する。
- ダブルクリックによる音高メモ設置位置は、2回目のクリック時点のポインタ位置を採用する。
- 新規音高メモの固定長は0.5秒であり、短いループでもループ境界に合わせて長さを特別に短縮・丸めない。既存の「クリック位置から既定長で置く」操作感を維持する。
- 再生中のループ境界では、原曲と音高メモの同期にUIフレーム程度の遅れや短いメモの聞き逃しが起こり得るため、短区間ループで確認する。
- ループ範囲内に収まる音高メモは、次の周回で正しい開始時刻・音高・長さで発音する想定とする。
- ループ範囲外へはみ出すメモは、終端を越えた部分がループジャンプで切れるが、次の周回でメモの開始位置がループ内なら再び正常に発音する。
- 再生中のループ範囲自体の編集は許可する。既存範囲のハンドル調整ではループを維持し、既存範囲以外から作り直す場合は押下直後に長さゼロとなって一時的にループが無効化され得る。一時的に旧範囲外を再生しても、新しい有効範囲の確定後に正しい位置へ戻るなら許容する。
- `Ctrl+Z` のテキスト入力との競合は既存のショートカット設計上の問題であり、v0.4.0項目1の実装を止める前提にはしない。
- 極小ループ時の再生位置線の逸脱は、今回の再生中編集とは切り分けた低優先度の異常系として扱い、現時点では対応しない。
- v0.4.0項目2として検討していた`Original / Notes / Mix`の専用プリセット／再生モードは実装しない。
- 手動比較は、原曲Muteと既存の全レイヤーMuteを組み合わせて行う。
- トップバーの原曲音量にはMute操作を追加する。Mute中も音量設定値は保持し、解除時に元の音量へ戻す。
- 項目3の自動比較ループでは、手動比較用の原曲Mute・全レイヤーMuteとは別に、比較中の設定を一時適用し、比較終了時にユーザー設定へ復元する仕組みを検討する。

# MVP ゴール

- v0.4.0項目1として、停止中の既存編集性を維持しつつ、再生中は有効なループ再生時だけ音高メモを安全に編集できる状態にする。
- 編集可否条件を明確化し、無効なループ中の編集を防ぐ。最小ループ長は安全上必須とはせず、必要な場合のみ操作感のために設定する。
- 再生中ドラッグ中もポインタ位置と時刻・音高の対応を安定させ、時間・音高ズームによる時刻・音高対応の不意な変化を防ぐ。画面をまたぐループ範囲は現行実装上指定できないため、再生ヘッド追従による画面送りは対象としない。
- 再生中の新規配置・移動・リサイズは既存の編集規則を維持し、ループ範囲外へはみ出すこと自体でメモの長さや位置を自動改変しない。既存のループ範囲外メモも壊さず保持する。
- ループ再生中の追加・削除・移動・リサイズ・音高変更・Undoが、次周回の音高メモ再生へ正しく反映されることを実機で確認する。
- 手動比較については、トップバーの原曲Muteと既存の全レイヤーMuteを組み合わせて原曲／メモの比較ができる状態にする。
- v0.4.0項目3として、手動比較で使うMute機能を前提に、自動比較ループの仕様を定める。

# 非ゴール

- 自動採譜、正誤判定、BPM・拍・小節、クオンタイズ、MIDI編集／出力は対象外。
- v0.4.0項目1では、再生中のシーク、ページバー移動、速度・EQ変更は対象外。
- ループ再生中の編集仕様を理由に、スペクトログラム本体の毎フレーム再構築へ戻さない。
- 既存のループ範囲外メモを自動削除・自動変換することは対象外。
- ループ境界に合わせて新規メモの長さを特別に短縮・丸めることは対象外。
- 画面をまたぐループ範囲を前提とした再生ヘッド追従・表示範囲固定の対策は対象外。
- 最小ループ長を安全対策として必須化することは対象外。必要性が確認されるまでは任意の操作感調整として扱う。
- ループ範囲外メモの扱いや、短いループで固定長0.5秒のメモをどう収めるかなど、項目1の範囲で未決定の仕様を推測で固定しない。
- 極小ループ時の再生位置線の逸脱について、今回の再生中編集の修正とは切り分け、現時点では対応しない。
- v0.4.0項目2として、`Original / Notes / Mix`の専用プリセット／再生モードを実装することは対象外。
- 手動比較を新しい比較専用モードやプリセット状態として実装することは対象外。
- 項目3の自動比較ループを、手動比較用のMute操作と同一の一時状態として扱うことは対象外。

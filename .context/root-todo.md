# Auto ToDo Root

## テーマ

- `otomieru-boyer` の音声再生とスペクトログラム表示を、再生状態とUI更新を分離して安定・軽量にする

## 目的

- 再生中のロック競合や再生速度異常を解消する
- 再生位置とUI表示を同期しつつ、スペクトログラム全体を毎フレーム更新しない構成にする
- MVPでは必要十分な再生位置表示を軽量に実現する
- 再生中はスペクトログラムを読み取り専用にし、停止中・一時停止中にスペクトログラム上からシークできる構成にする
- 1画面を任意の開始位置から表示し、再生中は1画面分まるごと表示範囲を更新する。停止中は全体シークバーから表示開始位置を任意に変更できる構成にする
- 1画面の表示範囲と、曲全体の再生位置・ループ範囲を別の概念として扱う
- 曲長ベースのページ分割を再生ロジックの基準にせず、固定幅ビューポートとして表示を扱う方向で整理する
- ページ分割UIまで整ったため、実際のSTFT・静止スペクトログラム表示まで実装済み。サーモグラフィー風の配色と `Heat` 調整も実装済み。ループ範囲指定帯とスペクトログラム上の2本の境界線も実機で一致確認済み。`Loop Range` ラベルは削除し、ループスタートとループエンドの線を個別に微調整できるように実装済み。調整結果はループ再生へ即時反映される。ループ範囲作成と端点微調整のUIも帯の中で分離し、スペクトラム側のループ線ドラッグ処理を撤去済み。ループ開始線・終了線をスペクトラム画面からループ範囲帯まで連続して見えるよう描画した後、帯側の端点表示を三角ハンドルへ変更し、帯とスペクトラムをつなぐ補助線も撤去済み。三角ハンドルの向きを `▶    ◀` として範囲を内側から挟む見た目に変更済み。実機で三角ハンドルの掴みやすさを確認する段階まで進んだ

## 前提認識

- `audio::player` はロック競合しない構造へ組み直し済み
- PCMは不変共有、再生状態と位置はAtomic管理へ変更済み
- `cargo check` でビルド成立を確認済み
- 実機で再生が改善し、通常再生速度は正常化している
- UI更新対象は限定する
  - 高頻度更新: 再生中のスペクトログラム上の再生位置を示す縦線
  - 低頻度更新: 1画面分の表示範囲切り替え
  - 必要時のみ更新: Open、Seek、Stop、表示開始位置変更、将来の選択範囲変更
- スペクトログラムは自動スクロールするが、ヌルヌル動かさない
- 再生中は1画面分再生したら次の表示範囲へ切り替える方式とする
- 再生位置の縦線のみヌルヌル動かし、再生中は手動シークを受け付けない
- 停止中・一時停止中は表示開始位置を任意に変更でき、必要なら滑らかに位置更新する
- ツールバーの再生用シークバーは不要とする
- シーク操作はスペクトログラム側へ寄せる
- 内部の再生位置は秒ベースで保持する
- ツールバーの再生用シークバーを外し、スペクトログラム側にページの概念を追加済み
- 再生中はスペクトログラムを読み取り専用として扱い、停止中のみスペクトログラムクリックによるページ内シークを受け付ける構成まで実装済み
- スペクトログラム下部のシークバーは、表示中ページ内の再生位置を示すものではなく、曲全体のページ列を対象とするページシークバーとする
- 例えば1曲が30ページに分割される場合、ページシークバーは30ページ全体を対象とし、ページジャンプに使用する
- 再生位置の縦線は表示中ページ内の位置を示すもので、全体ページシークバーとは同期させない
- 曲長ベースのページ分割を実装済みで、`page_count = ceil(曲の分数 × 6)` をベースに `8`〜`48`ページへ収める
- 実際の1ページ長は `duration_seconds / page_count` から求める
- スペクトログラム表示側も動的なページ情報を利用し、現在ページとページ内の時間範囲を表示する
- 縦方向・横方向のズームはページ分割をフレキシブルにするため、MVPから除外する
- 再生中はページ内の再生位置縦線を動かし、停止中は全体ページシークバーからページを移動する構成を実装済み
- 全体ページシークバーでページ移動した場合は、そのページの先頭秒へシークする導線を実装済み
- 全体ページシークバーとページ内の再生位置縦線は別概念として扱う
- ページ内再生位置の縦線は、全体ページシークバー上の対応位置にある黄色い丸を表示せず、上から下まで通る縦線として表示する
- 曲長ベースのページ分割を表示へ反映し、再生中のページ内縦線更新と停止中の全体ページバーからページ先頭へ移動する導線を実装済み
- `RustFFT` を追加し、STFTの事前計算を実装済み
- `src/analysis/spectrum.rs` に表示用スペクトログラムデータ構造を実装済み
- 音源読み込み時に解析し、スペクトログラムを `Track` へ格納する構成を実装済み

- スペクトログラム表示は実機で確認済み
- 強弱が分かりにくかったため、サーモグラフィー風の配色へ変更済み
- ツールバーに `Heat` 調整を追加し、`-24 dB`〜`+24 dB` の表示ゲインを変更できるようにした
- `Heat` を上げると弱い成分が見えやすくなり、下げると強い成分を中心に表示できる
- `cargo check` でビルド成立を確認済み
- 表示密度や色の出方にはまだ調整余地がある
- ループ範囲指定帯は現在表示中の1ページを基準に扱うよう修正済み

- ループ範囲作成UIと開始・終了端点の微調整UIを帯の中で分離済み

- 三角ハンドルのドラッグ判定は開始端・終了端に割り当て済み
- 三角ハンドルの向きを `▶    ◀` に変更し、ループ範囲を内側から挟む見た目に調整済み
- `cargo check` でビルド成立を確認済み
- ページまたぎループ時の問題は、曲長ベースのページ分割そのものよりも、`表示単位` と `再生・編集単位` がずれることが本質的な論点として整理された
- ページは再生やループの基準ではなく、表示上の概念として独立させる案が現時点で有力
- 再生位置・ループ範囲・シークは秒ベースで独立して扱い、ページをまたぐループでも再生ロジック側ではページ境界を意識しない構成を検討する

## MVP ゴール

- 音声を正常速度で再生できる
- 再生中はスペクトログラムを読み取り専用として扱える
- スペクトログラム上の再生位置を縦線で確認できる
- スペクトログラムは1画面単位で切り替わり、画面内では縦線だけが滑らかに移動する
- 再生中にスペクトログラム全体を滑らかにスクロールさせない
- 停止中・一時停止中はスペクトログラム上からシークできる
- スペクトログラム下部の全体シークバーから、任意の位置を表示開始位置として選択できる
- 全体シークバーと画面内の再生位置の縦線を同一概念として扱わない
- 表示開始位置を任意の秒として扱い、固定幅の1画面を描画できる
- 再生中は1画面分進むごとに表示範囲を更新する
- ループ範囲が画面境界をまたいでも、再生・編集処理を表示範囲に依存させない
- MVPでは縦方向・横方向のズームを扱わない
- 音声からSTFTを事前計算し、静止したスペクトログラムを表示できる
- スペクトログラムで音の強弱を視認しやすい配色・表示ゲインを調整できる
- 表示範囲と再生・編集を独立して扱える構成を目指す

## 非ゴール

- スペクトログラム全体のヌルヌルした自動スクロール
- 再生中の手動シーク操作
- ツールバーに常時表示する再生用シークバー
- 初期段階での高度な選択範囲変更
- 不要なUIの毎フレーム更新
- 全体シークバーと再生位置の縦線の完全同期
- 縦方向・横方向のズーム
- ズームに伴うフレキシブルなページ分割
- ページを再生・ループ処理の単位として扱うこと
- 曲長から固定ページ番号を決めることを再生・表示ロジックの中心にすること

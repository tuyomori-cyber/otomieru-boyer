# Auto ToDo Root

## 現在地

- 実用機能は実装済み：音程維持付き速度変更、±1オクターブ、5バンドEQ、ループ、シーク、スペクトログラム、時間／音高ズーム、日本語UIフォント。
- 音声処理は `Streaming worker → 固定長SPSCリング → CPAL callback`。Rubber Band R2を使用する。
- 主要操作と音程維持、オクターブ、ズーム、可変高表示、日本語フォントは実機確認済み。
- README、仕様書、ToDoを実装済み実用機能に合わせて整理済み。
- READMEのコマンド例について、不要な `svg` 表示を避けるためコードブロックの言語指定を外す修正済み。
- 5バンドEQはworker内で実際に再生音へ適用し、スペクトラム表示にも同じEQカーブを色強度へ反映する構成として実装済み。
- 元のスペクトラム解析データは保持したままEQ表示を反映するため、表示側の追加処理は軽量な構成になっている。
- 再生で強調した帯域がスペクトラム画面でも明るくなる表示方針をREADMEに追記済み。
- EQツールボックスに5バンドすべてを `0.0 dB` に戻す `Reset EQ` ボタンを追加済み。
- `Reset EQ` は再生停止中のみ操作でき、`cargo check` は通過している。
- Open 画面の古い「Open から音源を読み込む MVP の土台です。次にデコードと再生を実装します。」という案内文は、現在はデコード・再生とも実装済みのため不要と整理した。
- Open 画面の案内・状態表示は、MVP 開発途中の説明ではなくステータスバーとして扱い、未読み込み時は音源読み込みを促し、読み込み後はファイル名・長さ・サンプルレート・チャンネル数などを表示する方針とした。
- 静的解析で検出された未使用コード・Clippy警告を解消し、旧DSP経路、未使用のデバッグ集計コード、ストリーミング処理・UIのClippy指摘などを整理済み。
- 条件分岐、配列走査、テスト初期化などを現行Rustに合わせて整理し、音声機能の挙動は維持した。
- `cargo clippy --all-targets -- -D warnings` は警告ゼロで通過している。
- `cargo test` は6件すべて成功している。
- `cargo check` と `git diff --check` も通過している。

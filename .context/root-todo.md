# v0.5以降のロードマップ

## 方針

- v0.5では、耳コピ中に頻繁に使う入力操作をまとめて改善する。
- v0.6では、音源再読込時の解析コストをキャッシュで削減する。
- v0.7では、比較ループを任意列のループシーケンサーへ拡張する。
- v0.8では、試聴音エンジンを拡張してMIDIキーボードと追加音色に対応する。

## v0.5.0 — 操作感の改善（完了）
- [x] `Shift + 左ドラッグ`で、押下位置から解放位置までの可変長音高メモを作成できるようにする。左ダブルクリックによる0.5秒メモ設置は維持する。
- [x] 横・縦の表示バーを、クリック位置と表示範囲の中心が一致する操作感へ改善する。
- [x] スペクトログラム上で`Shift + ホイール`による時間方向の表示移動を追加する。既存のホイール／`Ctrl + ホイール`によるズームは維持する。
- [x] 完全カスタマイズは行わず、「既定」「時間移動重視」など少数の操作プリセットを用意する。
- [x] 入力判定と機能実行をアクション単位へ分離し、将来のキー・マウス・MIDI割当に備える。
- [x] 操作プリセットと主要操作を説明するアプリ内ヘルプを追加する。

## v0.6.0 — 解析キャッシュ（実装・実機確認完了）

- [x] STFT・スペクトログラムの解析結果を、音源横の専用バイナリキャッシュへ保存する。
- [x] キャッシュをsidecar JSONへ含めず、通常のプロジェクト保存から分離する。
- [x] 音源の照合情報と解析形式バージョンでキャッシュを検証し、不一致・破損時は再解析する。
- [x] キャッシュは一時ファイルを経由して原子的に保存する。
- [x] キャッシュ利用時も再生用の音声デコードは必要であることを仕様として明示する。
- [ ] 初回解析中のUI停止を解消する、デコードを含む非同期ロードとロード中経過時間の動的表示は、優先度を下げて以降の版で再検討する。

## v0.7.0 — ループシーケンサー

- [ ] 比較ループを、`Original`・`Notes`・`Mix`を任意順・任意回数で並べられるループシーケンサーへ拡張する。
- [ ] 比較列の追加、削除、並べ替え、既定値への復帰を提供する。
- [ ] 音声コールバックから安全に読める、上限付きのシーケンス表現を導入する。
- [ ] 比較列の変更時は、ループ始端へ戻して新しい列の先頭から再開する。
- [ ] 比較列を曲単位のsidecarへ保存し、旧保存形式の読込互換を維持する。

## v0.8.0 — MIDI試聴と音色拡張

- [ ] 接続済みMIDI入力デバイスを選択し、Note On／Note Offで試聴音を鳴らせるようにする。
- [ ] MIDI鍵盤の和音に対応するため、試聴音を複数ボイスで管理する。
- [ ] MIDIのベロシティを試聴音量へ反映するか、実装開始前に決定する。
- [ ] CC0など再配布可能な軽量音源を採用し、ブラス・ギター等の試聴音色を追加する。
- [ ] 音源ごとのライセンスと同梱情報を`docs/dependencies.md`へ記載する。
- [ ] MIDIデバイス未接続、切断、対応外メッセージを安全に扱い、Linux実機で確認する。

# Auto ToDo Root

## テーマ

- `otomieru-boyer` の音声再生とスペクトログラム表示を、再生状態とUI更新を分離して安定・軽量にする

## 目的

- 再生中のロック競合や再生速度異常を解消する
- 再生位置とUI表示を同期しつつ、スペクトログラム全体を毎フレーム更新しない構成にする
- MVPでは必要十分な再生位置表示を軽量に実現する
- 再生中はスペクトログラムを読み取り専用にし、停止中・一時停止中にスペクトログラム上からシークできる構成にする
- 1曲全体を複数ページに分割し、表示中の1ページ内の再生位置と、曲全体のページ選択を別の概念として扱う
- 曲の長さに応じてページ数を内部計算し、曲ごとに適切なページ分割を行う
- ページ分割UIまで整ったため、次はプレースホルダ描画から実際のSTFT・静止スペクトログラム表示へ進む

## 前提認識

- `audio::player` はロック競合しない構造へ組み直し済み
- PCMは不変共有、再生状態と位置はAtomic管理へ変更済み
- `cargo check` でビルド成立を確認済み
- 実機で再生が改善し、通常再生速度は正常化している
- UI更新対象は限定する
  - 高頻度更新: 再生中のスペクトログラム上の再生位置を示す縦線
  - 低頻度更新: スペクトログラムの表示ページ切り替え
  - 必要時のみ更新: Open、Seek、Stop、ページ送り、将来の選択範囲変更
- スペクトログラムは自動スクロールするが、ヌルヌル動かさない
- 1ページ分再生したら次ページへ切り替える方式とする
- 再生位置の縦線のみヌルヌル動かし、再生中は手動シークを受け付けない
- 自動シークはページが更新されたら、その分だけ進む
- 停止中・一時停止中はスペクトログラム上から自由にシークでき、必要なら滑らかに位置更新する
- ツールバーの再生用シークバーは不要とする
- シーク操作はスペクトログラム側へ寄せる
- 内部の再生位置は秒ベースで保持する
- ツールバーの再生用シークバーを外し、スペクトログラム側にページの概念を追加済み
- 再生中はスペクトログラムを読み取り専用として扱い、停止中のみスペクトログラムクリックによるページ内シークを受け付ける構成まで実装済み
- スペクトログラム下部のシークバーは、表示中ページ内の再生位置を示すものではなく、曲全体のページ列を対象とするページシークバーとする
- 例えば1曲が30ページに分割される場合、ページシークバーは30ページ全体を対象とし、ページジャンプに使用する
- 再生位置の縦線は表示中ページ内の位置を示すもので、全体ページシークバーとは同期させない
- 曲長ベースのページ分割を実装済みで、`page_count = ceil(曲の分数 × 6)` をベースに `8`〜`48`ページへ収める
- 実際の1ページ長は `duration_seconds / page_count` から求める
- スペクトログラム表示側も動的なページ情報を利用し、現在ページとページ内の時間範囲を表示する
- 縦方向・横方向のズームはページ分割をフレキシブルにするため、MVPから除外する
- 再生中はページ内の再生位置縦線を動かし、停止中は全体ページシークバーからページを移動する構成を実装済み
- 全体ページシークバーでページ移動した場合は、そのページの先頭秒へシークする導線を実装済み
- 全体ページシークバーとページ内の再生位置縦線は別概念として扱う
- ページ内再生位置の縦線は、全体ページシークバー上の対応位置にある黄色い丸を表示せず、上から下まで通る縦線として表示する
- 現在のスペクトログラム領域はプレースホルダ描画であり、次は `STFT` と静止スペクトログラム本体を実装する段階

## MVP ゴール

- 音声を正常速度で再生できる
- 再生中はスペクトログラムを読み取り専用として扱える
- スペクトログラム上の再生位置を縦線で確認できる
- スペクトログラムはページ単位で切り替わり、ページ内では縦線だけが滑らかに移動する
- 再生中にスペクトログラム全体を滑らかにスクロールさせない
- 停止中・一時停止中はスペクトログラム上からシークできる
- スペクトログラム下部のページシークバーで曲全体のページ位置を確認・変更できる
- ページシークバーとページ内の再生位置の縦線を同一概念として扱わない
- 曲の長さに応じてページ数を計算し、曲ごとにページ分割できる
- MVPでは縦方向・横方向のズームを扱わない
- 音声からSTFTを事前計算し、静止したスペクトログラムを表示できる

## 非ゴール

- スペクトログラム全体のヌルヌルした自動スクロール
- 再生中の手動シーク操作
- ツールバーに常時表示する再生用シークバー
- 初期段階での高度な選択範囲変更
- 不要なUIの毎フレーム更新
- ページシークバーと再生位置の縦線の完全同期
- 縦方向・横方向のズーム
- ズームに伴うフレキシブルなページ分割

# Otomieru Boyer 全体仕様書

> 対象バージョン: **v0.6.0（実装済み・実機確認待ち）**
> 状態: v0.5.0までの機能に加え、解析キャッシュを実装済み。既知課題は[v0.5.0テスト項目](<../test/v0.5.0 テスト項目.md>)、v0.6.0の確認は[v0.6.0テスト項目](<../test/v0.6.0 テスト項目.md>)を参照。

v0.3.0で追加した音高メモとプロジェクト保存、v0.4.0の比較ループ、v0.5.0の操作感改善、v0.6.0の解析キャッシュを含む現行アプリケーションの全体仕様を定義する。版ごとの詳細は[v0.3.0 音高メモ仕様書](<v0.3.0 音高メモ仕様書.md>)、[v0.4.0 仕様書](<v0.4.0 仕様書.md>)、[v0.5.0 仕様書](<v0.5.0 仕様書.md>)、[v0.6.0 仕様書](<v0.6.0 仕様書.md>)を参照する。

## 1. 概要

Otomieru Boyerは、音源をスペクトログラムとピアノロールで可視化し、反復再生と音高メモで耳コピを支援するLinux向けデスクトップアプリケーションである。自動採譜や正誤判定は行わず、ユーザーが見つけた音を記録し、原曲と重ねて耳で確認することを目的とする。

## 2. 再生・表示

| 機能 | 仕様 |
| --- | --- |
| 再生制御 | 再生、一時停止、停止、曲頭へ移動 |
| シーク | 停止中にスペクトログラムを左クリック |
| ループ | タイムラインのドラッグで範囲指定し、`Loop`で有効化。`消去`で範囲を解除 |
| 比較ループ | Loop ONかつ有効範囲で`比較`をONにすると、`Original → Notes → Mix`を各1周ずつ反復 |
| 速度 | 0.50x / 0.75x / 1.00x / 1.25x / 1.50x。音程を維持 |
| オクターブ | -1 oct / 0 st / +1 oct。速度変更と独立 |
| 原曲音量 | ツールバーで0〜100%を調整。確認音・音高メモとは独立 |
| 表示範囲 | MIDI 24〜108。ホイール操作はマウス設定に従う（既定: ホイールで時間ズーム、Ctrl＋ホイールで音高ズーム、Shift＋ホイールで時間移動）。下部横バーで時間、右端縦バーで音高の表示範囲を移動 |

速度、オクターブ、EQは停止中だけ変更できる。スペクトログラムは表示幅に応じて解析フレームを集約し、テクスチャキャッシュを再利用する。再生線はUI側で補間して描画する。

音源を開く際は再生用に毎回デコードする。STFT・スペクトログラム結果だけは、音源と同じフォルダの`<音源ファイル名>.otomieru.spectrum.bin`へ保存して再利用する。音源名、サイズ、更新日時、長さ、サンプルレート、解析形式・STFT設定が一致しない場合やキャッシュが破損している場合は、安全に再解析して置換する。通常のプロジェクト保存はこのバイナリキャッシュを変更しない。

時間表示の横バーは再生中も操作でき、音声位置・ループ範囲・比較フェーズを変更しない。音高表示の縦バーも同様に表示だけを移動する。縦バーは押下開始後、カーソルがバー外へ出てもボタンを離すまでドラッグを維持する。

## 3. 試聴、分析ツール、設定

メニューバーの`分析ツール`は、横幅・縦幅を変更でき、内容が収まらない場合は縦横スクロールするダイアログを開く。今聴いている音を調べるための次の項目を縦順で表示し、各項目は折り畳める。

1. EQ
2. 基音強調
3. 音色
4. チューニング
5. レイヤー

EQ、基音強調、チューニングの説明は見出し横のⓘ、または見出しのホバーで表示する。

メニューバーの`設定`は、曲別sidecarに保存しないユーザー共通のマウス操作設定を開く。ホイール3操作と可変長メモ設置の修飾キーを、プリセットまたは個別設定で変更できる。設定は`~/.config/otomieru-boyer/settings.json`（または`XDG_CONFIG_HOME`配下）へ、`format_version: 1`を含めて保存する。

### EQ

100 Hz、250 Hz、1 kHz、4 kHz、10 kHzの5バンドを各±12 dBで調整する。再生音のEQ処理と、スペクトログラムの明るさの補正に同じカーブを使う。

### 基音強調

倍音列から基音候補を強調する表示専用の補正である。強調率、キー、スケール、12音の個別指定、指定外音の減衰率を設定できる。再生音には影響しない。

### 試聴音

スペクトログラムを押している間、対応する音高を確認音として鳴らし、ピアノロールの該当鍵を着色する。

- 音色: ピアノ、シンセストリングス、矩形波
- 試聴音量: ツールバーで0〜50%
- チューニング: A4=430〜450 Hz、初期値440 Hz

チューニングは確認音と音高メモ再生の基準音にだけ反映し、元音源の解析・表示は変更しない。矩形波には確認音量へ25%の出力補正を掛ける。

## 4. 音高メモとレイヤー

音高メモは、時間、長さ、MIDI音高を持つ、音源上の伸縮可能な記録である。音価、BPM、クオンタイズ、ベロシティの概念は持たない。

| 操作 | 結果 |
| --- | --- |
| 左ダブルクリック | 選択中レイヤーに0.5秒のメモを作成 |
| 設定した修飾キー + 左ドラッグ | 押下位置から解放位置までの可変長メモを作成。既定はShift |
| 右クリック | 対象メモを削除 |
| 左右端の右ドラッグ | 長さを変更 |
| 中央の右ドラッグ | 時間・音高を移動 |
| `Ctrl+Z` | 作成・削除・移動・変更を取り消し |

レイヤーは6つ固定であり、初期名は`Layer 1`〜`Layer 6`とする。追加、削除、並べ替え、色編集は行わない。レイヤーごとに固定色を割り当て、選択中レイヤーを前面に描画する。

レイヤーUIでは入力先、名前、表示、Mute、音量、透明度を操作できる。一括操作として、全レイヤーの音量、表示、Mute、透明度を同じ値に設定できる。表示と発音は独立し、Muteでないレイヤーのメモは表示状態にかかわらず発音する。

停止中はすべての音高メモ操作を行える。有効なループ範囲を再生中も同じ操作とUndoを行えるが、Loop OFFまたは範囲なしの通常再生中は編集できない。テキスト入力欄にフォーカスがある間の`Ctrl+Z`は、メモUndoではなく入力欄のUndoを優先する。

表示、Mute、音量、透明度は永続化しない実行時設定である。新規起動およびsidecar読込時に、全レイヤーを表示ON、Mute OFF、音量100%、透明度100%へ初期化する。

## 5. 音高メモ再生

原曲再生中、現在位置に重なる音高メモを、選択中の音色とA4基準音で原曲と同時に鳴らす。最大64声まで扱い、シーク、停止、ループ折返し時に再同期する。レイヤーの音量とMuteはメモ再生へ反映するが、ツールバーの試聴音量は影響しない。

比較ループ中は、Originalで原曲だけ、Notesで音高メモだけ、Mixで両方を出力する。Notes／Mixのメモ再生には、その時点のレイヤーMute・音量設定を使用する。Originalでのメモ無音化は一時的な出力制御で、レイヤー設定自体は変更しない。Loop OFFまたは範囲消去時は比較をOFFにする。Loop ONのままStopした場合は比較ONを維持し、再開時はOriginalから始める。

音声コールバックではロック、動的メモリ確保、DSP計算を行わない。

## 6. プロジェクト保存

音源と同じフォルダへ`<音源ファイル名>.otomieru.json`を保存する。`ファイル → 保存`または`Ctrl+S`で保存し、音源を開いたときに自動読込する。

保存時は一時ファイルへ書き込み、同期後に置換する。保存成功時だけ未保存状態を解除する。読込時は形式バージョンと値を検証し、音源情報が一致しない場合は警告を表示して読み込む。

### 保存対象

| 項目 | 保存 |
| --- | --- |
| 音源照合情報 | する |
| A4基準Hz、EQ、基音強調 | する |
| レイヤーID・名前 | する |
| 音高メモ | する |
| 表示、Mute、レイヤー音量、透明度 | しない |
| 選択レイヤー・選択メモ・Undo履歴 | しない |
| 再生速度、オクターブ、ループ、原曲音量、試聴音量、音色 | しない |

旧形式のJSONにレイヤーの実行時設定が含まれていても読み込めるが、これらの値は破棄して初期値を適用する。

## 7. 対象外

- 自動音高推定・自動採譜・正誤判定
- BPM推定、拍・小節、音価、クオンタイズ
- ベロシティ、MIDI CC、MIDI入出力
- VST、エフェクトによる音作り、楽譜作成

## 8. 動作環境・ライセンス

- 対象環境: Linux
- ビルド時: Rust stable、`librubberband-dev`、`pkg-config`
- 日本語UI: Noto Sans CJKまたはIPAex
- ライセンス: GPL-2.0-or-later

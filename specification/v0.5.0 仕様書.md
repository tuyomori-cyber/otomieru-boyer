# v0.5.0 仕様書

## テーマ

> 耳コピ中に最も頻繁に行う操作を、止まらず・迷わず行えるようにする

v0.5では分析機能や音声処理を増やさず、音高メモの入力とスペクトログラムの表示移動を改善する。対象は、可変長メモ設置、表示バー、ホイール操作、操作プリセット、アプリ内ヘルプである。

実装後の確認項目は、[v0.5.0 テスト項目](../test/v0.5.0%20テスト項目.md)にまとめる。

## 1. 可変長の音高メモ設置

既存の左ダブルクリックによる0.5秒メモ設置は維持する。加えて、スペクトログラム上で設定した修飾キー（既定は`Shift`）を押しながら左ドラッグすると、押下位置から解放位置までの長さを持つ音高メモを作成する。

| 操作 | 結果 |
|---|---|
| 左ダブルクリック | 既定長0.5秒の音高メモを作成する |
| 設定した修飾キー + 左ドラッグ（既定: `Shift`） | 押下位置から解放位置までの可変長音高メモを作成する |

- 音高は押下位置の音高を使う。
- 時刻は押下位置と解放位置から決める。右から左へドラッグした場合も、左側を開始位置として正の長さを持つメモにする。
- 最小長、音源末尾でのクランプ、作成後の選択状態は既存メモと同じ規則に従う。
- 作成は1回のUndo対象とする。
- 停止中と、有効なループ範囲を再生中だけ利用できる。ループが無効な通常再生中は利用できない。
- `Shift`を押している間は、通常の左クリックによるシークと試聴音開始を行わない。

## 2. 表示範囲の移動

### 2.1 表示バー

スペクトログラム下部の時間表示バーと右端の音高表示バーは、クリック位置が現在の表示範囲の中心になるよう移動する。表示範囲のつまみを直接ドラッグした場合も、押下位置とつまみ内の相対位置を保って移動する。

- 時間表示バーは、音声位置・ループ範囲・比較シーケンスを変更しない。
- 音高表示バーは、音声・音高メモ・ループを変更しない。
- ドラッグ開始後は、カーソルがバー外へ出てもボタンを離すまで操作を維持する。

### 2.2 ホイールによる時間移動

スペクトログラム上のホイール操作を次のように定義する。修飾キーは操作プリセットまたは個別設定で変更できる。

| 操作 | 結果 |
|---|---|
| ホイール（既定） | 時間方向のズーム |
| `Ctrl + ホイール`（既定） | 音高方向のズーム |
| `Shift + ホイール`（既定） | 時間方向の表示移動 |

時間方向の表示移動量は、現在の表示幅に比例させる。表示範囲は音源の先頭・末尾を越えないようクランプする。

タッチパッドの連続スクロールジェスチャーについて、入力イベント数に依存しない移動量へ整形する操作感の調整はv0.5の対象外とする。

## 3. 操作プリセット

v0.5ではキー・マウス操作の完全なカスタマイズは提供しない。少数のプリセットから選択したうえで、ホイール3操作と可変長メモ設置の修飾キーだけを個別に変更できる。

| プリセット | 目的 |
|---|---|
| 既定 | ホイール: 時間ズーム、`Ctrl`: 音高ズーム、`Shift`: 時間移動。可変長メモは`Shift + 左ドラッグ` |
| 時間移動重視 | ホイール: 時間移動、`Ctrl`: 時間ズーム、`Shift`: 音高ズーム。可変長メモは`Shift + 左ドラッグ` |

- 個別設定では、時間ズーム・音高ズーム・時間移動を、`なし`・`Shift`・`Ctrl`からそれぞれ1つずつ重複なく割り当てる。すでに使われている修飾キーを選ぶと、2つの操作の割当を入れ替える。
- Linuxではデスクトップ環境の拡大縮小と競合するため、`Alt + ホイール`および`Alt + 左ドラッグ`は選択肢に含めない。旧設定に`Alt + ホイール`が残っていた場合も、アプリ内操作としては実行しない。
- 可変長メモ設置は`Shift`・`Ctrl`または無効から選べる。
- 個別設定でプリセットと異なる組合せにした場合は、表示を「カスタム」とする。

内部では、入力判定と機能実行を分離し、`時間ズーム`、`音高ズーム`、`時間移動`、`可変長メモ設置`などのアクション単位で扱う。将来の自由なキー・マウス・MIDI割当は対象外とする。

操作プリセットと個別設定はユーザー環境に属する設定として扱い、曲単位のsidecarには保存しない。設定はXDG設定ディレクトリ（既定では`~/.config/otomieru-boyer/settings.json`）に保存する。このJSONは`format_version: 1`を持つ独立した保存形式とし、未対応の版は読み込まない。版番号を持たない開発中の旧設定は、読込時に形式1へ移行する。

## 4. アプリ内ヘルプ

ツールバーから開ける読み取り専用のヘルプウィンドウを追加する。

- 外部ブラウザやネットワーク接続を必要としない。
- 再生・ループ・比較、音高メモ編集、表示移動、操作プリセットを説明する。
- 表示中の操作プリセットに対応した操作説明を表示する。
- READMEと仕様書を正とし、ヘルプ内容の更新漏れを避ける。

### 4.1 メニューバー

常用の耳コピ操作はツールバーへ残し、低頻度操作とガイドの入口としてメニューバーを設ける。

| メニュー | 項目 |
|---|---|
| ファイル | 音源を開く、保存 |
| 編集 | 元に戻す |
| 再生 | 再生／一時停止、先頭へ戻る、停止 |
| 表示 | 時間・音高表示を初期化 |
| 分析ツール | EQ、基音強調、音色、チューニング、レイヤーを調整する |
| 設定 | マウス操作設定を開く |
| ヘルプ | 操作ガイドを開く |

- 再生・停止、速度・ピッチ、Loop・比較、音量、Heatはツールバーに常時表示する。
- 「選択」メニューは、独立した選択操作が増えるまで導入しない。
- 操作ガイドは、現在選択中のマウス操作設定から可変長メモとホイール操作の説明を動的に表示する。
- EQ・基音強調・音色・チューニング・レイヤーは、今聴いている音を調べるための「分析ツール」としてまとめる。マウス操作設定は分析に属さないため、独立した「設定」画面に置く。

## 5. 対象外

- 任意のキー・ボタン・修飾キーを利用者が自由に割り当てる機能
- MIDIコントローラーへの操作割当
- 音高メモのクオンタイズ、BPM、拍・小節
- 再生中の速度、オクターブ、EQ変更
- タッチパッドの連続スクロールジェスチャーに対する時間移動量の調整

## 6. 確認項目

- 可変長メモを左右どちらの方向へドラッグしても、意図した開始位置・長さ・音高で作成できる。
- 可変長メモの作成を1回のUndoで取り消せる。
- ループ再生中と停止中での編集可否が既存仕様と一致する。
- 横・縦バーのクリックとドラッグで、表示範囲が視覚上の位置と一致して移動する。
- 各ホイール操作が競合せず、音声・ループ・比較状態を変更しない。
- プリセット切替・個別設定・設定の再起動後の復元をLinux実機で確認する。
- メニューバーからの各操作と、ヘルプ内の現在のマウス設定表示をLinux実機で確認する。

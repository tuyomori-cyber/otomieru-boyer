v0.4のテーマ：再生を止めずに耳コピする

実装後の確認項目は`../test/v0.4.0 テスト項目.md`にまとめる。

v0.3で「音高メモを置く・編集する・レイヤー管理する・原曲と重ねて鳴らす・保存する」まで一通り完成したので、v0.4では新しい分析機能を増やすのではなく、聴く → 試す → 置く → 比較する → 修正する、をループ再生中に連続して行えるようにする。

**有効なループ範囲を再生中に限って**音高メモ編集を解禁する。通常再生中は、従来どおり音高メモを編集できない。

1. 再生中の音高メモ編集

ループ再生中に限り、ループを止めずに音高メモを操作可能にする。

音高メモの新規配置
削除
長さ変更
時刻方向への移動
音高方向への移動
Undo
スペクトログラム上での試聴音

特に短い区間をループしながら、

聴く → 候補音を鳴らす → メモを置く → 次のループで確認 → 半音違う → ドラッグ → 次のループで再確認

までStop/Playなしで行える状態を目標にする。

音高メモの設置・削除・長さ変更・時刻／音高方向への移動・Undoは、**ループが有効で実際に再生している間のみ**許可する。停止中は従来どおり操作できる。ループが無効な通常再生中は許可しない。スペクトログラム上の試聴音は既存どおり、再生状態にかかわらず利用できる。

既存の音高メモ操作自体はv0.3ですでに揃っているので、 v0.4では「新しい編集機能」というより既存操作のリアルタイム化。

2. 比較ループ

短区間ループ時に、再生状態をループごとに自動切り替えできるモード。

例えば、

Original → Notes → Mix → Original → Notes → Mix → …

と繰り返す。

比較ループ中の出力は、次のように切り替える。

- Original: 原曲を鳴らし、音高メモは比較中の一時制御として全レイヤーをMute
- Notes: 原曲をMuteし、音高メモは各レイヤーの現在のMute・音量設定に従って再生
- Mix: 原曲を鳴らし、音高メモは各レイヤーの現在のMute・音量設定に従って再生

比較ループ中もレイヤーミキサーは操作可能とする。レイヤーごとのMute・音量、および全レイヤーMute・全レイヤー音量の変更は、NotesとMixへそのまま反映する。例えばレイヤー1だけを鳴らす設定や、全レイヤーの音量が0でNotesが無音になる設定も許可する。

Originalでの全レイヤーMuteは比較中だけの一時的な出力制御であり、各レイヤーが持つMute・音量設定そのものは変更しない。したがって、次のNotesまたはMixでは、その時点のレイヤーミキサー設定へ戻る。比較終了時にもレイヤー設定の退避・復元は発生せず、ユーザーが設定した値がそのまま残る。

LoopをOFFにした場合は、比較も無条件にOFFにする。LoopがONのまま再生をStopした場合は、再びループ再生する可能性があるため比較ONを維持し、比較順だけOriginalから再開する。

Loopの横にある`消去`ボタンでループ範囲を消去できる。消去すると有効なループ範囲がなくなるため、比較も自動的にOFFになる。Loopのチェック状態は維持し、次に範囲を指定した際に再びループ再生できる。範囲を消去した後の`|<`は曲先頭へシークする。

2.1 表示範囲の移動

再生中もスペクトログラム下部の横バーで時間方向の表示範囲を移動できる。表示だけを移動し、音声位置、ループ範囲、比較フェーズは変更しない。再生ヘッドが表示右端を越えたときは既存の自動追従が働くが、その挙動の違和感は低優先度の既知課題とする。

音高ズーム後は、スペクトログラム右端の縦バーで高音側・低音側の表示範囲を移動できる。縦バーはドラッグ中にカーソルがバー外へ出ても、ボタンを離すまで操作を維持する。これも音声やメモを変更しない。

v0.4のUIでは、各状態の周回数、順序、比較対象を変更する設定は設けない。各状態を1周ずつ、Original → Notes → Mixの固定順で再生する。

ただし内部実装では「Originalの次はNotes」のような状態間の固定遷移を持たず、比較対象のシーケンスと現在位置を順番に進める構造にする。v0.4の既定シーケンスは`[Original, Notes, Mix]`とする。これにより、将来必要になった場合はシーケンスを`[Original, Original, Notes, Notes, Mix, Mix]`へ変更することで、UIや音声切替の基本構造を変えずに各状態を複数周へ拡張できるようにする。

これによって現在手動でやっている、

「原曲を聴く」
→「メモだけ聴く」
→「重ねて聴く」
→「また原曲を聴く」

という操作そのものを自動化する。

クロスフェードは現時点では入れない。 実際に手動で3状態を切り替えて試した結果、離散的なOriginal / Notes / Mixだけでも差異を十分認識しやすかったため。

重要なのは、自動的に正誤判定する機能ではないこと。

比較操作は自動化するが、「同じか違うか」を判断するのは人間の耳。

これは現在の「自動採譜や正誤判定を行わない」という基本仕様とも一致します。

3. リアルタイム化しないもの

何でも再生中に変更可能にするわけではない。

特に、

EQ / 基音強調

は耳コピループへ入る前に「聴きやすい状態を作る前処理」と考えるため、現状どおり停止中のみ変更でも問題ない。

速度・オクターブについても、v0.4の主目的ではない。現在は速度・オクターブ・EQが停止中のみ変更可能という仕様なので、 必要性が実使用で出てからリアルタイム化を検討する。

つまりv0.4でリアルタイム化する対象は、基本的に耳で音を探している最中に頻繁に触るものに限定する。

まとめると、v0.4はかなり綺麗に一文で表せます。

v0.4 — ループ再生中に限り、再生を止めることなく音を試し、音高メモを配置・修正し、原曲・メモ・MIXを比較できる耳コピワークフローを実現する。

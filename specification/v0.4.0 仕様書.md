# v0.4.0 仕様書

## テーマ

> 再生を止めずに耳コピする

v0.3では、次の機能が一通り完成した。

- 音高メモを置く
- 音高メモを編集する
- レイヤーを管理する
- 原曲と音高メモを重ねて鳴らす
- 編集内容を保存する

v0.4では新しい分析機能を増やすのではなく、次の作業をループ再生中に連続して行えるようにする。

> 聴く → 試す → 置く → 比較する → 修正する

実装後の確認項目は、[v0.4.0 テスト項目](../test/v0.4.0%20テスト項目.md)にまとめる。

## 1. 再生中の音高メモ編集

有効なループ範囲を再生している間は、ループを止めずに音高メモを操作できるようにする。ループが無効な通常再生中は、従来どおり音高メモを編集できない。

### 1.1 対象操作

- 音高メモの新規配置
- 音高メモの削除
- 音高メモの長さ変更
- 音高メモの時刻方向への移動
- 音高メモの音高方向への移動
- Undo
- スペクトログラム上での試聴音

特に短い区間をループしながら、次の一連の作業をStop／Playなしで行える状態を目標とする。

> 聴く → 候補音を鳴らす → メモを置く → 次のループで確認 → 半音違う → ドラッグ → 次のループで再確認

### 1.2 操作条件

| 再生状態 | 音高メモの設置・編集・Undo | 試聴音 |
|---|---:|---:|
| 停止中 | 可 | 可 |
| 有効なループ範囲を再生中 | 可 | 可 |
| ループが無効な通常再生中 | 不可 | 可 |

音高メモの設置・削除・長さ変更・時刻／音高方向への移動・Undoは、停止中、またはループが有効で実際に再生している間のみ許可する。スペクトログラム上の試聴音は既存どおり、再生状態にかかわらず利用できる。

既存の音高メモ操作自体はv0.3ですでに揃っている。そのため、v0.4で扱うのは「新しい編集機能」ではなく、既存操作のリアルタイム化である。

## 2. 比較ループ

短区間のループ再生時に、出力状態を周回ごとに自動で切り替えるモードを追加する。

```text
Original → Notes → Mix → Original → Notes → Mix → …
```

### 2.1 フェーズごとの出力

| フェーズ | 原曲 | 音高メモ |
|---|---:|---|
| Original | 再生 | 比較中の一時制御として全レイヤーをMute |
| Notes | Mute | 各レイヤーの現在のMute・音量設定に従って再生 |
| Mix | 再生 | 各レイヤーの現在のMute・音量設定に従って再生 |

比較ループ中もレイヤーミキサーを操作できる。次の変更はNotesとMixへそのまま反映する。

- レイヤーごとのMute・音量
- 全レイヤーMute
- 全レイヤー音量

レイヤー1だけを鳴らす設定や、全レイヤーの音量が0でNotesが無音になる設定も許可する。

Originalでの全レイヤーMuteは、比較中だけの一時的な出力制御である。各レイヤーが持つMute・音量設定そのものは変更しない。したがって、次のNotesまたはMixでは、その時点のレイヤーミキサー設定へ戻る。比較終了時にもレイヤー設定の退避・復元は発生せず、ユーザーが設定した値がそのまま残る。

### 2.2 Loop・Stopとの関係

| 操作 | 比較の状態 |
|---|---|
| LoopをOFFにする | 比較を無条件にOFFにする |
| LoopがONのままStopする | 比較ONを維持し、比較順だけOriginalへ戻す |
| Loop横の「消去」で範囲を消去する | 比較を自動的にOFFにする |

Loop横の「消去」ボタンでループ範囲を消去できる。消去後もLoopのチェック状態は維持し、次に範囲を指定した際に再びループ再生できるようにする。範囲を消去した後の「|<」は曲先頭へシークする。

### 2.3 v0.4の固定シーケンス

v0.4のUIには、各状態の周回数、順序、比較対象を変更する設定を設けない。各状態を1周ずつ、次の固定順で再生する。

```text
Original → Notes → Mix
```

ただし、内部実装では「Originalの次はNotes」のような状態間の固定遷移を持たせない。比較対象のシーケンスと現在位置を順番に進める構造とし、v0.4の既定シーケンスを次のように定義する。

```text
[Original, Notes, Mix]
```

これにより、将来必要になった場合は、たとえば次のシーケンスへ変更することで、UIや音声切り替えの基本構造を変えずに各状態を複数周へ拡張できるようにする。

```text
[Original, Original, Notes, Notes, Mix, Mix]
```

### 2.4 目的と位置づけ

比較ループは、現在手動で行っている次の操作を自動化する。

1. 原曲を聴く
2. メモだけ聴く
3. 重ねて聴く
4. 再び原曲を聴く

クロスフェードは現時点では導入しない。手動で3状態を切り替えて試した結果、離散的なOriginal／Notes／Mixだけでも差異を十分に認識しやすかったためである。

比較操作は自動化するが、「同じか違うか」を判断するのは人間の耳である。自動的に正誤判定する機能ではなく、現在の「自動採譜や正誤判定を行わない」という基本仕様にも一致する。

## 3. 表示範囲の移動

### 3.1 時間方向

再生中も、スペクトログラム下部の横バーで時間方向の表示範囲を移動できる。移動するのは表示だけであり、次の状態は変更しない。

- 音声位置
- ループ範囲
- 比較フェーズ

再生ヘッドが表示右端を越えたときは既存の自動追従が働く。この挙動の違和感は、低優先度の既知課題とする。

### 3.2 音高方向

音高ズーム後は、スペクトログラム右端の縦バーで高音側・低音側の表示範囲を移動できる。縦バーは、ドラッグ中にカーソルがバー外へ出ても、ボタンを離すまで操作を維持する。

移動するのは表示だけであり、音声や音高メモは変更しない。

## 4. リアルタイム化しないもの

すべての操作を再生中に変更可能にするわけではない。

### 4.1 EQ・基音強調

EQと基音強調は、耳コピループへ入る前に「聴きやすい状態を作る前処理」と考える。そのため、現状どおり停止中のみ変更可能とする。

### 4.2 速度・オクターブ

速度とオクターブのリアルタイム変更は、v0.4の主目的には含めない。現在は速度・オクターブ・EQが停止中のみ変更可能であり、実使用で必要性が明らかになった段階でリアルタイム化を検討する。

v0.4でリアルタイム化する対象は、耳で音を探している最中に頻繁に操作するものへ限定する。

## 5. まとめ

> **v0.4 — ループ再生中に限り、再生を止めることなく音を試し、音高メモを配置・修正し、原曲・メモ・Mixを比較できる耳コピワークフローを実現する。**

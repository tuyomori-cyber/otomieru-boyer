# v0.7.0 仕様書

## テーマ

> 比較ループを、耳で確かめたい順番へ組み立てる

v0.4の比較ループ`Original → Notes → Mix`を、任意の比較ステップ列を繰り返すループシーケンサーへ拡張する。

## 1. シーケンス

比較シーケンスは、次の3種類のステップを1個以上並べた列である。

| ステップ | 原曲 | 音高メモ |
|---|---:|---|
| Original | 再生 | 一時的に全レイヤーMute |
| Notes | Mute | 現在のレイヤーMute・音量設定に従って再生 |
| Mix | 再生 | 現在のレイヤーMute・音量設定に従って再生 |

各ステップは1回のループ範囲再生に対応する。末尾まで再生したら、先頭へ戻って繰り返す。

例:

```text
Original → Original → Notes → Mix → Mix
```

初期シーケンスは従来どおりとする。

```text
Original → Notes → Mix
```

## 2. シーケンス編集

比較設定UIから、ステップの追加、削除、並べ替えを行えるようにする。

- シーケンスは空にできない。
- ステップ数には、音声スレッドで安全に扱える固定の上限を設ける。
- 上限値はUIへ明示する。
- シーケンスを既定値へ戻す操作を提供する。

比較を有効にできる条件は従来どおり、LoopがONかつ有効なループ範囲があることとする。

## 3. 再生中の変更

比較シーケンスを変更したときは、比較を無効化せず、ループ始端へシークして変更後の先頭ステップから再開する。変更時に旧シーケンスと新シーケンスが混在しないことを優先する。

- Loop OFFまたはループ範囲消去時は、比較をOFFにする。
- Stop時は比較ONを維持し、再開時はシーケンスの先頭から開始する。
- Pause時は、現在のステップと再生位置を維持する。
- レイヤーMute・音量は従来どおり比較中も変更でき、Notes／Mixへ即時反映する。

## 4. 実装上の制約

比較シーケンスは、原曲再生と音高メモ再生の両方の音声コールバックから安全に参照できなければならない。

- 音声コールバックではMutex取得、動的メモリ確保、DSP計算を行わない。
- UIがシーケンスを更新する際、音声側が部分更新された列を観測しないようにする。
- シーケンス本体と現在位置を、上限付きかつ原子的に切り替えられる表現で扱う。

## 5. 保存

シーケンスは曲単位の設定としてsidecarへ保存する。

- 既存のv0.4形式を読めるよう、保存形式の移行処理を用意する。
- 旧形式を読んだ場合は、既定シーケンス`[Original, Notes, Mix]`を適用する。
- 不正なステップ、空列、上限超過は読込エラーとして扱う。

## 6. 対象外

- ステップごとの個別音量、クロスフェード、待機時間
- ステップ単位でのレイヤーMute・音量プリセット
- 複数の命名済みシーケンスを保存・切替する機能
- 自動的な正誤判定

## 7. 確認項目

- 同一ステップを連続させた列を含め、すべての列が設定順に周回する。
- 変更直後にループ始端・先頭ステップへ確実に戻る。
- Stop、Pause、Loop OFF、範囲消去、範囲変更時の状態遷移がv0.4の規則と一致する。
- sidecarの旧形式読込、新形式保存・読込、不正データ拒否を自動テストする。
- 短いループ、長い列、レイヤーミキサー操作を含む実機テストを行う。

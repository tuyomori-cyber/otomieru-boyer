# v0.7.0 仕様書

## テーマ

> 耳コピに常用する道具を手元に置き、比較ループを聴きたい順番へ組み立てる

> 状態: リリース済み。確認結果は[v0.7.0テスト項目](<../test/v0.7.0 テスト項目.md>)を参照。

v0.4の比較ループ`Original → Notes → Mix`を、任意の比較ステップ列を繰り返すループシーケンサへ拡張する。UI上の名称は`比較パターン`とする。同時に、耳コピ中に頻繁に使う調整をユーザーが選んでツールバーから開ける、常用ツールパレットを導入する。

## 1. ツールと設定

耳コピの作業中に使う機能を`ツール`、入力方法などアプリの操作環境を変更する機能を`設定`として扱う。EQのように表示・聴覚の両方へ作用する機能や、レイヤーのように記録・表示・再生にまたがる機能を、用途別に無理に分類しない。

### 常用ツールパレット

- ツールバーの`ツール`ボタンで、常用ツールパレットを開く。パレットはリサイズ・スクロール可能なダイアログとし、各ツールは折り畳める。
- 初期状態では、`EQ`、`基音強調`、`音色`、`チューニング`、`レイヤー`、`比較パターン`を表示する。
- メニューバーの`ツール`から`マスターパレット…`を開き、パレットへ表示するツールを変更できる。少なくとも1つのツールを表示し、既定構成へ戻す操作を提供する。
- マスターパレットの機能名はドラッグで並べ替えられる。ツールダイアログは、この順番を維持してチェック済みのツールだけを表示する。チェックを外したツールもマスターパレット上の位置を維持し、再チェック時はその位置で再表示する。
- パレットの表示対象とマスター順はユーザー共通の`settings.json`へ保存する。曲ごとのsidecarには保存しない。旧設定を読む場合は既存の表示順をマスター順の先頭として引き継ぐ。
- 既存の各ツールが扱う値の保存先と動作条件は変えない。ループシーケンサとパレット構成はユーザー共通の`settings.json`へ、EQなどの曲固有設定は曲ごとのsidecarへ保存する。

`設定`には、曲別sidecarに保存しないマウス操作などの操作環境設定を置く。ツールパレットの構成もユーザー共通設定だが、編集入口はパレットと同じ`ツール`メニューに置く。

## 2. ループシーケンサ

ループシーケンサは、次の3種類のステップを1個以上並べた列である。画面上では`比較パターン`と表示する。

| ステップ | 原曲 | 音高メモ |
|---|---:|---|
| Original | 再生 | 一時的に全レイヤーMute |
| Notes | Mute | 現在のレイヤーMute・音量設定に従って再生 |
| Mix | 再生 | 現在のレイヤーMute・音量設定に従って再生 |

各ステップは1回のループ範囲再生に対応する。末尾まで再生したら、先頭へ戻って繰り返す。

例:

```text
Original → Original → Notes → Mix → Mix
```

初期シーケンスは従来どおりとする。

```text
Original → Notes → Mix
```

## 3. ループシーケンサ編集

常用ツールパレットの`比較パターン`から、ステップの追加・削除・変更を行えるようにする。

- 各ステップは選択ボックスで`Original`、`Notes`、`Mix`、`なし`から選ぶ。`なし`を選ぶと、そのステップを削除して以降の行を詰める。
- 最下部の空の選択ボックスでステップを追加する。
- シーケンスは空にできず、最後の1ステップは削除できない。
- ステップ数の上限は10とする。上限到達時は追加欄の代わりにその旨を表示する。

比較を有効にできる条件は従来どおり、LoopがONかつ有効なループ範囲があることとする。

## 4. 再生中の変更

ループシーケンサを変更したときは、比較を無効化せず、ループ始端へシークして変更後の先頭ステップから再開する。変更時に旧シーケンスと新シーケンスが混在しないことを優先する。

- Loop OFFまたはループ範囲消去時は、比較をOFFにする。
- Stop時は比較ONを維持し、再開時はシーケンスの先頭から開始する。
- Pause時は、現在のステップと再生位置を維持する。
- レイヤーMute・音量は従来どおり比較中も変更でき、Notes／Mixへ即時反映する。

## 5. 実装上の制約

ループシーケンサは、原曲再生と音高メモ再生の両方の音声コールバックから安全に参照できなければならない。

- 音声コールバックではMutex取得、動的メモリ確保、DSP計算を行わない。
- UIがシーケンスを更新する際、音声側が部分更新された列を観測しないようにする。
- パターン本体と現在位置を、上限付きかつ原子的に切り替えられる表現で扱う。

## 6. 保存

ループシーケンサと常用ツールパレットの表示項目は、ユーザー共通の`settings.json`へ保存する。曲ごとのsidecarには保存しない。

- ループシーケンサの設定がない旧`settings.json`を読んだ場合は、既定シーケンス`[Original, Notes, Mix]`を適用する。
- 空列、上限超過は既定シーケンスへ戻す。

## 7. 対象外

- ステップごとの個別音量、クロスフェード、待機時間
- ステップ単位でのレイヤーMute・音量プリセット
- 複数の命名済みループシーケンサを保存・切替する機能
- 自動的な正誤判定
- ツールごとの独立した表示状態・複数の命名済みパレット

## 8. 確認項目

- 同一ステップを連続させた列を含め、すべての列が設定順に周回する。
- 変更直後にループ始端・先頭ステップへ確実に戻る。
- Stop、Pause、Loop OFF、範囲消去、範囲変更時の状態遷移がv0.4の規則と一致する。
- `settings.json`の旧形式読込、新形式保存・読込、空列・上限超過時の既定値復帰を自動テストする。
- 短いループ、長い列、レイヤーミキサー操作を含む実機テストを行う。
- 初期パレット、表示項目・並び順の変更、既定構成への復帰、および`settings.json`への保存・読込を確認する。

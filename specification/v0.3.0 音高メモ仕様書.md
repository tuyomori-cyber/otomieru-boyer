# OtoMieru Boyer v0.3.0 ― 音高メモ仕様

## 1. 目的

音高メモは、耳コピ中にユーザーが判断した音高を音源の時間軸上へ記録し、原曲と同時に鳴らして確認する機能である。

> 見る → 聴く → 音高を推測 → メモを置く → 原曲と同時再生 → 耳で確認 → 修正

自動採譜、正誤判定、MIDI編集・出力、拍・小節・クオンタイズは対象外とする。

## 2. データモデル

音高メモは音符ではなく、時間×音高座標上に置く伸縮可能な記録である。

```rust
struct PitchMemo {
    id: MemoId,
    start_sec: f64,
    duration_sec: f64,
    pitch_midi: i32,
}
```

- `start_sec`: 音源上の開始位置
- `duration_sec`: 表示範囲と発音時間。音価は表さない
- `pitch_midi`: MIDI 0〜127の音高
- `id`: sidecar内で一意な永続ID

メモIDは全レイヤーを通して一意とする。開始位置は0秒以上、長さは0より大きく、終端は音源長を超えない。

## 3. 編集

編集は停止中だけ可能とする。左クリックの確認音操作を維持するため、作成・編集には左ダブルクリックと右ボタンを使用する。

| 操作 | 結果 |
| --- | --- |
| 左単押し・左長押し | 従来どおり再生位置を移動し、確認音を鳴らす |
| 左ダブルクリック | 選択中レイヤーへ長さ0.5秒のメモを作成 |
| メモ上で右クリックして離す | 対象メモを削除 |
| メモの左右端で右ドラッグ | 左端または右端をリサイズ |
| メモ中央で右ドラッグ | 時間と音高を移動 |
| `Ctrl+Z` | 作成・削除・移動・音高変更・長さ変更を取り消す |

メモ中央にポインタを置くと移動可能であることを示すカーソル表示を行う。端部では横方向リサイズ用カーソルを表示する。メモが重なった場合、選択中レイヤーを優先し、その中では前面のメモを操作する。

## 4. レイヤー

音高メモは6つの固定レイヤーで管理する。初期名は`Layer 1`〜`Layer 6`で、レイヤーの追加、削除、並べ替え、色編集は行わない。

各レイヤーは次のデータを持つ。

```rust
struct PitchMemoLayer {
    id: LayerId,
    name: String,
    memos: Vec<PitchMemo>,
}
```

`LayerId`は1〜6の永続IDで、固定パレットの色を決める。全レイヤーのメモを同時表示し、選択中レイヤーを前面に描画する。

### 実行時レイヤー設定

設定ダイアログでは、入力先、表示、Mute、音量、透明度をレイヤーごとに操作できる。全レイヤーの音量、表示、Mute、透明度を同時に同じ値へ変更する操作も提供する。

| 設定 | 役割 | 保存 |
| --- | --- | --- |
| 表示 | スペクトログラム上のメモを表示するか | しない |
| Mute | メモ再生を鳴らすか | しない |
| 音量 | メモ再生の音量 | しない |
| 透明度 | メモの塗りと枠線の透明度 | しない |

表示と発音は独立する。起動時およびsidecar読込時には、全レイヤーを表示ON、Mute OFF、音量100%、透明度100%へ必ず初期化する。旧sidecarにこれらの項目があっても、読込後は初期値を使う。

## 5. 答え合わせ再生

原曲再生位置がメモの範囲内にあるとき、メモを確認音と同じ音色・A4基準音で発音する。最大64声とし、シーク、停止、ループ折返し時に発音状態を同期し直す。

- 音色: ピアノ／シンセストリングス／矩形波
- 基準音: A4=430〜450 Hz
- 音量: レイヤー音量にメモ再生用の基準振幅を掛ける
- Mute: 発音しない
- 表示OFF: 発音には影響しない
- ツールバーの試聴音量: メモ再生には影響しない

アプリは正誤を判定しない。原曲とメモ音の一致はユーザーが耳で判断する。

## 6. 保存形式

保存ファイルは音源と同じフォルダの`<音源ファイル名>.otomieru.json`とする。例: `song.flac` → `song.flac.otomieru.json`。

```json
{
  "format_version": 1,
  "audio": {
    "file_name": "song.flac",
    "file_size_bytes": 12345678,
    "modified_unix_ms": 1735689600000,
    "duration_seconds": 245.31,
    "sample_rate_hz": 44100
  },
  "project_settings": {
    "preview_reference_a4_hz": 444.5,
    "equalizer_gains_db": [0.0, -2.0, 1.5, 0.0, 0.0],
    "fundamental_analysis": {
      "emphasis": 60.0,
      "scale_root": 0,
      "scale_preset": "major",
      "emphasized_pitch_classes": [true, false, true, false, true, true, false, true, false, true, false, true],
      "unemphasized_pitch_attenuation": 30.0
    }
  },
  "layers": [
    {
      "id": 1,
      "name": "Bass",
      "memos": [
        {
          "id": 1,
          "start_sec": 12.43,
          "duration_sec": 0.8,
          "pitch_midi": 40
        }
      ]
    }
  ]
}
```

`format_version`はアプリ版ではなく保存形式の版である。`audio`は対象音源の照合に使い、絶対パスは保存しない。ファイル名、サイズ、更新日時、長さ、サンプルレートが一致しない場合は警告を表示する。

保存対象は曲固有設定、レイヤーID・名前、音高メモだけである。選択状態、採番位置、Undo履歴、表示、Mute、レイヤー音量、透明度、再生速度、オクターブ、ループ、原曲音量、試聴音量、音色は保存しない。

書込みは一時ファイルを経由し、同期後に置換する。Saveまたは`Ctrl+S`で保存し、保存成功時だけ未保存状態を解除する。音源読込時にはsidecarを自動読込する。

## 7. 非ゴール

- 自動音高推定・正誤判定
- BPM、拍、小節、クオンタイズ、グリッドスナップ
- ベロシティ、MIDI CC、MIDI編集／出力
- VST、エフェクト、楽譜作成

> **見つけた音を、書いて、重ねて、聴き直す。**

# v0.8.0 仕様書

## テーマ

> 指で探す試聴音を、鍵盤と音色の選択肢で広げる

v0.8では、外部MIDIキーボードでの試聴音入力と、ブラス・ギター等の追加音色を提供する。

## 1. MIDIキーボード入力

### 1.1 デバイス選択

設定画面で検出したMIDI入力デバイスを一覧表示し、試聴音に使うデバイスを選択できるようにする。

- デバイス未接続時もアプリは通常どおり起動・利用できる。
- 選択中のデバイスが切断された場合は、安全に入力を停止して状態を表示する。
- MIDI入力の選択はユーザー環境に属する設定であり、曲単位のsidecarには保存しない。

### 1.2 発音

| MIDIメッセージ | 動作 |
|---|---|
| Note On（velocity > 0） | 対応する試聴音を開始する |
| Note Off、またはvelocity 0のNote On | 対応する試聴音を停止する |
| その他のメッセージ | 無視する |

- MIDI音高0〜127を受け付ける。表示範囲外の音も発音できるが、スペクトログラムとピアノロールの着色は表示可能範囲に従う。
- 複数のNote Onを同時に扱い、和音を試聴できる。
- 最大同時試聴数には安全な上限を設ける。上限を超える入力は新規音を追加しない。
- v0.8でベロシティを音量へ反映するかは、実装前に決定する。反映しない場合もNote On／Offの意味は維持する。

マウスによるスペクトログラム上の試聴音は、従来どおり利用できる。マウス入力とMIDI入力は互いに停止させず、同時に鳴らせる。

## 2. 試聴音エンジン

現在の単音試聴を、複数の独立した試聴ボイスとして管理する。

- 音声コールバックではMutex取得、動的メモリ確保、DSP計算を行わない。
- MIDIイベントはUI／入力側から安全な制御値として音声側へ伝える。
- 既存の音高メモ再生用ボイスと、試聴用MIDIボイスの上限・世代管理を分離する。
- 比較ループ中のOriginal／Notes／Mixによる音高メモの出力制御は、MIDI試聴音には適用しない。

## 3. 追加音色

試聴音の音色として、既存のピアノ、シンセストリングス、矩形波に加え、ブラス、ギターなどを追加する。

- 採用する音源はCC0など、アプリのGPL-2.0-or-later配布と両立する再配布可能なものに限定する。
- 音源サイズ、対応音域、ループポイント、出力音量を確認する。
- 音色ごとの過大な音量差を補正する。
- 既存のA4基準ピッチ設定を全試聴音色へ適用する。
- 音高メモ再生も選択中の音色を使用する既存仕様を維持する。

追加する音源の出典、ライセンス、変更内容は`docs/dependencies.md`へ記載する。

## 4. 対象外

- MIDI出力、MIDIファイル入出力
- MIDI CC、プログラムチェンジ、ピッチベンド、アフタータッチ
- MIDIを用いた音高メモの自動作成や録音
- VSTや任意のSoundFont読込
- ユーザー自身による音源ファイルの追加

## 5. 確認項目

- 接続・未接続・切断を含むMIDIデバイス状態をLinux実機で確認する。
- Note On／Off、velocity 0、単音、和音、上限超過を確認する。
- MIDI試聴とマウス試聴、音高メモ再生、比較ループを同時に使っても異常な残音・二重停止がないことを確認する。
- 各追加音色の音域、A4基準ピッチ、音量、ライセンス表記を確認する。
- 音声スレッドのリアルタイム制約を守る単体テストと、実機音声テストを行う。
